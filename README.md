samsonterrence.github.io
Minimalist black-and-silver personal portfolio website for Terrence Samson, built with pure HTML, CSS, and JavaScript.
Typography
Display / Headings: Syne
Body / UI: Plus Jakarta Sans
Code / Metadata: Geist Mono
Setup & Deployment
Extract all files (index.html, style.css, script.js) into the root folder of the samsonterrence.github.io repository.
Open script.js and update LAB_TASKS_FOLDER_URL on line 4 with the direct link to his Lab Tasks repository or subfolder on GitHub.
Commit and push to the main branch.
